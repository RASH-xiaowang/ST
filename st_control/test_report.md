## 发现并修复的 Bug

### Bug 1: 资源预览系统 - JSON/代码文件预览缺失
**文件**: src/lib/kb/ResourcePreview.svelte
**问题**: previewType 映射了 'code' 类型（json, py, js 等），但模板无对应渲染块，显示"暂不支持预览此格式"
**修复**: 添加代码预览块和样式
**状态**: ✅ 已修复并验证

### Bug 2: Wiki 摘要提取 - 页面不存在错误
**文件**: src-tauri/src/kb/wiki/extract.rs
**问题**: extract_page_meta 在页面不存在时返回错误，导致大量警告日志
**修复**: 页面不存在时返回 Ok(()) 跳过提取
**状态**: ✅ 已修复并验证

### Bug 3: Python 文件上传失败
**文件**: src-tauri/src/kb/parse/mod.rs
**问题**: parse_document 不支持 .py 文件类型，返回"暂不支持的文件类型"
**修复**: 添加 Python 及常见代码文件类型到支持列表
**状态**: ✅ 已修复并验证
